# Cronograma Huguenotes

Cronograma acadêmico do Seminário Huguenotes: semestres, módulos, disciplinas
e a agenda de cada professor.

## Development

Você precisa do Node.js instalado.

```sh
git clone https://github.com/dihviny25-lab/seminario-huguenotes.git
cd seminario-huguenotes
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS

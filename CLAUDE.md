# Instruções para agentes de IA neste repositório

Todo o trabalho neste projeto (correção, melhoria ou nova função) segue o fluxo
**issue → branch → pull request → merge (deploy)** descrito em [CONTRIBUTING.md](CONTRIBUTING.md).
Leia esse arquivo antes de começar qualquer tarefa e siga-o à risca, inclusive:

- Criar uma issue no GitHub para a tarefa antes de implementá-la.
- Sempre mencionar a issue na descrição do PR (`Closes #<número>`).
- Nunca commitar/mergear direto na `main`.

Responda sempre em português (preferência do usuário).

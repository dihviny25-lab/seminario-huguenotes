# Uso do fluxo Superpowers

Este diretório registra especificações e planos de implementação antes de mudanças relevantes no sistema. A prática adotada aqui é: definir o problema, limitar escopo, escrever critérios de aceite, implementar em branch dedicada, validar com testes e revisão e só então integrar à `main`.

Os arquivos em `specs/` descrevem comportamento e decisões de produto. Os arquivos em `plans/` descrevem a sequência técnica de implementação.
